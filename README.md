# 10 个热门旅游城市：景点口碑的真实规律

> 用 Python 爬取去哪儿网 **455 个真实景点**数据，回答一个具体问题：
> **门票越贵，景点就越值得去吗？**

---

## 问题

旅游平台上，每个景点都有评分和评论数。作为游客，我们想问的是：

1. **门票价格和口碑有关系吗？**（贵的景点真的更好？）
2. **哪个城市的景点"口碑最稳"？**
3. **"热度高"的景点评价就更好吗？**

为了回答这些，我采集了 10 个热门旅游城市的景点数据。

---

## 数据

| 项目 | 说明 |
|---|---|
| 来源 | 去哪儿网（piao.qunar.com），**真实爬取，非模拟数据** |
| 规模 | 原始 499 条 → 清洗后 **455 条** × 10 城市 × 24 字段 |
| 字段 | 评分、评论数、门票价格、标签、景区等级、地址、简介等 |
| 采集方式 | Python `requests` 解析列表页 + 详情页，调用**评论 API** 获取真实用户评论 |

**城市分布**：北京 50、武汉 50、成都 50、西安 50、重庆 47、上海 45、青岛 44、杭州 42、济南 39、南京 38

## ⭐ 数据质量问题：我剔除掉了 8.8% 的"假数据"

这是本项目**最值得说的部分**。

爬取过程中发现：网站的"相关推荐"链接会污染列表页，导致**非本地景点被错误归到某城市**。
例如济南的数据里混进了泰山、故宫、八达岭长城，杭州的数据里混进了兵马俑、黄鹤楼。

**检出与处理**：
- 建立「地标 → 真实城市」映射表（40+ 个知名地标）
- 检测名称与实际归属不符的记录
- **检出 44 条污染数据（占 8.8%），全部剔除**

| 受影响城市 | 污染条数 |
|---|---|
| 南京 | 11 |
| 济南 | 11 |
| 杭州 | 8 |
| 青岛 | 6 |
| 上海 | 5 |
| 重庆 | 3 |

> 如果不清洗这批数据，后续所有"城市排名"结论都是错的。清洗脚本见 [`src/clean.py`](src/clean.py)，质量报告见 `data/processed/quality_report.txt`。

## 3 个关键发现

### 发现 1：门票价格与口碑**几乎没有关系**

- 价格与评分的皮尔逊相关系数 = **-0.03**（接近于零）
- 免费景点平均分 **4.38**，收费景点平均分 **4.57**
- 独立样本 t 检验：**p = 0.10 > 0.05，差异不显著**

> **结论**：贵的门票**买不到**更好的口碑。免费景点（如西湖、外滩、天安门）的口碑并不比收费景点差。
> 这跟"一分钱一分货"的直觉相反——对游客来说是个有用的信号。

### 发现 2：热度高 ≠ 评价好

- 评论数与评分的相关系数 = **0.13**（极弱正相关）

> **结论**：评论多的景点不一定评分高。热度反映的是"知名度"，不是"满意度"。
> 有些景点人很多，纯粹因为它是地标，而不是因为它好玩。

### 发现 3：各城市口碑差异明显

| 城市 | 景点数 | 平均评分 | 免费占比 |
|---|---|---|---|
| **南京** | 38 | **4.61** | 10.5% |
| 杭州 | 42 | 4.55 | 100% |
| 青岛 | 44 | 4.53 | 97.7% |
| 济南 | 39 | 4.50 | 97.4% |
| 上海 | 45 | 4.40 | 100% |
| 重庆 | 47 | 4.37 | 100% |
| 北京 | 50 | 4.37 | 100% |
| 成都 | 50 | 4.30 | 100% |
| 西安 | 50 | 4.24 | 100% |
| **武汉** | 50 | **4.21** | 100% |

> **结论**：南京评分最高（4.61）但收费景点比例也最高（近 90% 要门票）；
> 武汉、西安评分相对靠后。注意——**这个排名受数据质量影响，仅供参考**（见局限性）。

## 方法与技术栈

```
数据采集  →  requests + 反爬处理（UA 池/重试）+ 评论 API
数据清洗  →  pandas（8 项任务：污染剔除/缺失值/去重/派生字段）
情感分析  →  SnowNLP 对真实评论打分
可视化    →  matplotlib + seaborn（箱线图/小提琴图/热力图）+ folium（地图）
```

**运行方式**：

```bash
pip install -r requirements.txt
python src/clean.py        # 清洗（含污染检测）
```

---

## ⚠️ 局限性（诚实说明）

1. **价格数据严重不完整**：455 条中仅 36 条有有效价格（南京为主），
   其他城市的价格字段大量缺失。**因此"价格与口碑无关"的结论应谨慎对待**，
   真实结论需要更完整的价格数据支撑。
2. **单一平台偏差**：数据仅来自去哪儿网，不同平台的评分体系可能有差异。
3. **样本量有限**：455 条对全国景点代表性有限。
4. **情感分析用的是通用模型**（SnowNLP），未针对旅游语料微调，可能存在误判。
5. **评论数作为"热度"代理指标**，受平台流量影响，不完全等于真实客流。
