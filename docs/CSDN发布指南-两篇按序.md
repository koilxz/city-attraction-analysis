# 第 1 篇：《我推翻了 8.8% 这个数字》

## 步骤 1：打开编辑器

浏览器打开：https://editor.csdn.net/md/

（**必须用 Markdown 编辑器**，别用富文本编辑器，代码块和表格会乱）

## 步骤 2：准备正文

文件位置：
```
D:\桌面\文件夹\2026作业\city-attraction-analysis\docs\CSDN发布稿-续-我推翻了8.8%这个数字.md
```

**先做一件事**：用记事本或 VS Code 打开它，全选复制。

## 步骤 3：填标题

标题栏（不是正文里）填这段：

```
一次景点数据爬取复盘（续）：我把「8.8% 脏数据」这个数字彻底推翻了
```

> ⚠️ 建议**保留这个长标题**。CSDN 是内容搜索型平台，长标题里带上"数据清洗""爬虫"等关键词更容易被搜到。

## 步骤 4：粘贴正文

把刚才复制的全部内容粘贴到编辑区。

**注意**：文件第一行是标题文字（没有 `#` 号），粘贴后如果标题和标题栏重复，**把正文第一行删掉**。

## 步骤 5：处理图片（重要，别跳过）

文章里有 **2 张图**，CSDN 粘贴 Markdown 时图片不会自动上传，要手动传：

| 图 | 文件路径 | 插在文章哪个位置 |
|---|---|---|
| 图 1 清洗前后对比 | `results\figures\14_clean_before_after.png` | 「**先说结论**」那一节末尾，紧跟"上图左边是逐城市对比…" |
| 图 2 评分分布对比 | `results\figures\15_rating_dist_before_after.png` | 「**八、我特意去验证：清洗有没有美化数据？**」那一节，紧跟"上图"那句 |

**操作方法**：
1. 在文章里找到要插图的位置，光标定位到那一行
2. 点工具栏的「图片」按钮
3. **把图文件拖进去**（图片在上面的路径里，用文件管理器找到后拖到编辑区）
4. 上传完成后，**把 Markdown 里那行 `![](results/figures/xxx.png)` 删掉**，避免重复

## 步骤 6：填右侧元信息

| 字段 | 填什么 |
|---|---|
| **文章类型** | 选 **原创**（必须选，原创有流量加权） |
| **标签**（最多 5 个） | `python`　`数据清洗`　`爬虫`　`数据分析`　`pandas` |
| **分类专栏** | 有「Python」或「数据挖掘」就选；没有就选「其他」 |

**摘要**（直接复制这段）：

```
上一篇我说污染率 8.8%，清洗后剩 455 条——这个数字是错的。真实情况是 499 条里剔除了 348 条，污染率 69.7%，最终只留下 151 条。本文讲清我在复核时发现了什么：三个自动校验规则为什么全部漏检了"景点在省内但不在本市"这类系统性误标，以及我如何用一张 128 条的人工核验表把它揪出来。
```

## 步骤 7：发布

点「发布」。

> ⚠️ 勾上 **"原创"** 声明。别勾"付费"，求职要的是曝光不是钱。

## ⚠️ 关于旧文怎么处理

已发布的旧文《从 499 条到 455 条，我剔掉的 8.8% 脏数据》
链接：https://blog.csdn.net/2401_86734821/article/details/167659876

**不建议删**。原因：

- 删了反而显得心虚，而且新人没有"更正声明"的必要
- 新文章里已经把旧文的数据指出来了，读者自己会对照
- 面试被问到时，你可以说"这是我第一版，后来自己发现错了，第二篇写了完整修正过程"——**这比一开始就正确更像真实的工程师**

**但建议做一件事**：发布续篇后，回到旧文文末**加一行更新说明**（用 CSDN 的编辑功能改就行）：

```
【更新】本文是初版结论，已被我的第二篇《我推翻了 8.8% 这个数字》修正：真实污染率不是 8.8% 而是 69.7%，
清洗后不是 455 条而是 151 条。原因是我最初的自动校验规则漏检了"景点在省内但不在本市"这类系统性误标。
```

这一行字是整件事里**性价比最高的一个动作** —— 主动标注错误的作者，面试官对他的信任度会明显提高。
