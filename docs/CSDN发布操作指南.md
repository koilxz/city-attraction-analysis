# CSDN 发布操作指南

> 配套文件：`CSDN发布稿-一次景点数据爬取复盘.md`（直接复制全文粘贴到 CSDN）

---

## 一、为什么需要这份发布稿

CSDN 的 Markdown 编辑器对原文有 3 处不兼容，发布稿已处理：

| 原文写法 | CSDN 的问题 | 发布稿的改法 |
|---|---|---|
| 一级标题 `# 标题` | CSDN 标题框会自动填，正文再写 `#` 会重复 | 去掉 `#`，标题只填在标题栏 |
| `> 引用块` 作为引言 | 部分版本渲染成灰底块不美观 | 保留，但精简为一句 |
| 文末 `⭐` emoji | 可能显示成方框 | 已去掉 emoji |

**其余内容（代码块、表格、图片位置）CSDN 完全兼容。**

---

## 二、发布步骤

### 第 1 步：进入写作页
打开 https://editor.csdn.net/md/ （Markdown 编辑器，推荐）

### 第 2 步：填标题
```
一次景点数据爬取复盘：从 499 条到 455 条，我剔掉的 8.8% 脏数据
```

### 第 3 步：粘贴正文
打开 `CSDN发布稿-一次景点数据爬取复盘.md`，**全选复制**，粘贴进编辑器。

> ⚠️ 注意：发布稿第一行就是标题文字且没有 `#`，粘贴后如果和标题栏重复，**把正文第一行删掉**。

### 第 4 步：填元信息（右侧栏）

| 字段 | 建议填写 |
|---|---|
| **分类专栏** | 新建「数据分析」或「Python 实战」专栏 |
| **文章类型** | 原创 |
| **标签**（最多 5 个） | `python` `数据分析` `pandas` `爬虫` `数据清洗` |
| **摘要** | 见下方 |

**摘要文案**（直接复制）：
```
一次真实的景点数据爬取复盘：从 499 条原始数据出发，发现并剔除了 8.8% 的跨城市污染记录，又揪出 13 条被伪编码成 0 分的缺失值。完整记录了"地标映射表交叉校验"和"伪零分识别"两个数据清洗方法，以及清洗后数据结论发生反转的全过程。
```

### 第 5 步：插入图片（可选但强烈建议）

CSDN 支持直接拖拽上传。图片在：
```
D:\桌面\文件夹\2026作业\city-attraction-analysis\results\figures\
```

**建议插入 2–3 张**（插在对应小节）：
- `04_price_rating_scatter.png` → 插在「结论 1：门票价格和口碑几乎没有关系」后面
- `01_city_spot_count.png` → 插在「结论 3：各城市口碑差异明显」后面
- `03_rating_boxplot.png` → 插在「结论 3」表格后面

### 第 6 步：发布

## 四、注意事项

- **原创声明**：勾选「原创」。CSDN 会对原创文章加权，也避免被搬运。
- **封面图**：CSDN 会自动从正文抓第一张图当封面，也可以在发布页手动上传。
- **审核**：新账号首篇可能审核 1–2 小时，正常现象。
- **不要勾"付费"**：求职作品要的是曝光，不是收益。
